### `Before`

Almost every lecture has a `Before` version, which was posted before the start of the lecture. The version without `Before` has some extra things that were typed during the lecture (e.g. worked out proofs, sometimes some extra comments). If you study these files, I recommend ignoring the `Before` versions.
